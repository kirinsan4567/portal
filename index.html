    アプリの概要・リンク

    01

    住宅ローン返済シミュレーター

    無料

    金利変動シナリオ、繰上返済、住宅ローン控除まで踏み込んで試算。将来の返済額をシナリオ別に比較できます。

    ※ Currently available in Japanese only

    アプリを開く →
    02

    不動産売却益計算シミュレーター

    有料

    譲渡所得税、減価償却、3,000万円特別控除まで対応。マンション・戸建ての売却損益を正確に算出します。ペアローン条件にも対応。

    ※ Currently available in Japanese only

    住宅ローン返済シミュレーターとのデータ連携機能搭載

    noteで詳細を見る →
    03

    すみかえNAVI

    有料

    売却と購入を同時に進める「住み替え」特有のスケジュールと資金繰りを可視化し、リスクを事前に把握。返済・売却シミュレーションデータを連携可能*。

    ※ Currently available in Japanese only

    *住宅ローン返済シミュレーター、不動産売却計算シミュレーターとのデータ連携機能搭載

    noteで詳細を見る →
    04

    Insights

    無料

    住宅ローン、不動産、プレスリリース等のニュースを毎日自動で集約。その他、独自の分析レポートやコラムも掲載。

    ※ Currently available in Japanese only

    アプリを開く →
    05

    東京マンション管理費・修繕費マップ

    無料

    東京23区を中心としたマンションの管理費・修繕積立金を比較。エリア・築年数・規模・デベロッパー等の条件で絞り込みや比較ができます。

    ※ Currently available in Japanese only

    アプリを開く →
    06

    生活利便性マップ

    無料経路検索は有料

    東京23区の暮らしやすさを地図で可視化。店の集積度・路線数・都心アクセスをヒートマップで確認でき、地図をクリックすると徒歩圏の駅・店舗数と利便性スコアを表示。目的地までの経路検索にも対応。

    ※ Currently available in Japanese only. An English version is under consideration.

    FAQ（よくある質問）

    Q.このサイトは何ですか？

    住宅ローンの返済、売却益の試算、住み替えの資金計画、街の暮らしやすさの確認など、住まいに関する意思決定を数字で支えるアプリをまとめたポータルサイトです。個人開発者「KIRIN」が制作・運営しています。

    Q.KIRINとは何者ですか？

    KIRINは、不動産・住宅ローン分野の情報発信やシミュレーターを開発している個人のクリエイターです。不動産や街づくり、建築、アート、データ分析を好みとしています。

    Q.このアプリは安全ですか？入力した情報はどこかに送られますか？

    各シミュレーターは、入力いただいた情報をお使いのブラウザ内で計算する設計を基本としており、外部のサーバーに送信・保存することはありません。なお、サイトの改善のためGoogle Analyticsを利用しており、閲覧ページや滞在時間などの匿名化されたアクセス情報のみを取得しています。入力していただいた金額やご家庭の情報がGoogle Analyticsに送られることはありません。詳しくはGoogleのプライバシーポリシーをご確認ください。

    Q.料金はかかりますか？

    住宅ローン返済シミュレーター、Insights、東京マンション管理費・修繕費マップは無料でご利用いただけます。生活利便性マップも無料でご利用いただけますが、経路検索機能は有料です（詳しくはnoteの記事をご覧ください）。不動産売却益計算シミュレーターとすみかえNAVIは有料で、note.comでご購入いただくとアプリへのリンクとパスコードが発行されます。

    Q.計算結果はそのまま信じてよいですか？

    各アプリの結果は一般的な計算ロジックに基づく「試算」です。実際の金利・税額・審査条件等は金融機関や税理士等の専門家にご確認のうえ、ご自身の判断でご利用ください。

    Q.不具合の報告や質問をしたい場合は？

    画面右上のXアカウント（@kirinsan4567）のDMにて受け付けています。アプリの不具合報告、使い方のご質問など、お気軽にご連絡ください。
